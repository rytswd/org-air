* D-P1 [HIGH] — reorder the rail; give the inspector the middle
*Symptom:* the round-11 rail order is Calendar, Summary, Filters, Actions,
*Inspector-last* — the inspector is a foot band below the item rows,
small + cramped ("too small").

*New order, top→bottom:* Calendar · Summary · *Inspector* · Filters ·
Actions.  The inspector moves up under Summary and *expands into the large
freed middle*; Filters + Actions sink to the rail foot.

** The hard part: the inspector is no longer a foot band
Round-11 put the inspector *below* the composed two-pane body, so its lines
were full-width =<item blanks><divider><rail inspector>= and the item
columns beside it were legitimately blank → it updated by *full-line*
replacement.  Moving it *into* the rail (between Summary and Filters) means
its rail lines now sit *beside real item rows*.  Two consequences the
contract must handle:

1. *Fixed reserved height.*  The inspector content varies per item (field
   count, title wrap).  If it grew/shrank mid-rail it would shove Filters/
   Actions and desync the rail from the item pane.  *Contract:* the
   inspector occupies a *fixed reserved region* = the freed middle rows
   (rail height − calendar − Summary − Filters − Actions − inter-block
   gaps).  Render the inspector *top-aligned* within the region and *pad
   the remainder with blank =org-air-inspector='-tagged rail lines* (the
   blank tail IS the "breathing/expand" the spec asks for).  Filters +
   Actions are *pinned to the rail foot* (extend the existing
   =org-air-rail-anchor-actions= foot-pin to cover both).  The reserved
   height is computed once per full render (Filters height doesn't change
   on point motion), so it is stable between renders.
2. *Column-only live update.*  =org-air-view--render-inspector-region= must
   now replace *only the rail columns* (everything from column
   =item-width + (string-width divider)= to end-of-line) of each region
   line, *preserving the item-row text beside it*.  The marker region
   brackets the fixed reserved rows; the new inspector-lines list is padded
   /truncated to *exactly* the region's line count so the region height
   never changes.  =org-air-view--inspector-geom= gains =:region-height=.
   *Do NOT* full-line-replace (it would clobber the item rows) and *do
   NOT* full-re-render on motion (flicker / point loss) — both round-11
   bans still hold.

** Use the room (the visible payoff)
With the middle reserved, the inspector can breathe (the spec's
"more fields/breathing/wrap"):
- raise =org-air-inspector-max-title-lines= default 3 → *4*;
- add a *blank breathing line* between the identity group (title/state/
  origin/tags) and the dates group, and before the derived Bucket line;
- let the tags wrap freely (already word-wrapped) — the extra rows are
  free now.
Keep every round-11 field + the prefix-svg =▌ Inspector= header.

=[byte]=: the rail block ORDER + the inspector's new mid-rail position +
reserved blanks change the rail fixtures wholesale → regen + *BLESS*.

* D-P4 [HIGH] — priority cookie as a colour-coded svg badge  [gui]
*Symptom:* =[#A]= / =[#B]= / =[#C]= render as plain text.  Make the
priority a small *svg badge* like an org-mode priority cookie, coloured by
level (A hot → C cool), reusing the round-10/11 *calm capsule* machinery so
it matches the date/tag pills.

*Contract:*
- defcustom =org-air-priority-colors= — alist =(?A . (LIGHT . DARK))= …;
  defaults *A = red* (=#D32F2F= / =#BF616A=), *B = orange* (=#E0631E= /
  =#D08770=), *C = yellow-green* (=#689F38= / =#A3BE8C=) — lower priority =
  cooler/quieter.  Themable; resolved light/dark like the accent palette.
  New helper =org-air-view--priority-color (char)=.
- defcustom =org-air-priority-style= (='badge | 'text), default ='badge
  (parallel to =org-air-tag-style= / =org-air-date-style=).
- *Render:* when ='badge + svg is available, *pillify the existing =[#A]=
  token* — box-fit to its text cell (=Ncols("[#A]") × char-px= = 4 cells,
  C2 pixel-lock holds), soft =org-air-pill-radius=, the *calm capsule*
  (no/low fill, hairline border) — but tinted in the *priority colour*:
  the label =[#A]= and the border both draw in =priority-color= (a touch
  stronger than the neutral tag border, since priority is salient).  This
  is a thin generalization of =org-air-view--svg-pillify=: add a
  =&key border-color= (priority passes its colour; tags/dates pass nil =
  the neutral =org-air-pill-border=).  The label keeps the full =[#A]=
  glyphs centred + width-fit (no new geometry).
- *TTY / fallback (mandatory):* the plain =[#A]= text in the existing
  =org-air-face-priority-a/-b/-c= (whose hues should be reconciled with
  =org-air-priority-colors= so text + badge agree).
- *Applies* on the item-row prefix (only priorities in
  =org-air-priority-show=, default =?A=) AND, as a GUI cosmetic, the
  inspector "state + priority" line.
- =[gui]= non-byte: the badge is an svg overlay over the *unchanged* =[#A]=
  text → *fixtures HOLD* (the byte gate asserts =[#A]= text + its face).

* D-P3 [MED] — solid continuous vertical divider (vs the line-spacing gap)
*Symptom:* round-11's =org-air-line-spacing= 0.15 (D-P2 #4 capsule calm)
opens a pixel gap *below every row*; the divider =│= glyph is drawn per
character cell and does NOT paint into that gap → the divider reads as a
*dashed/broken* vertical.

*Decision (pick one, per the brief): move the row breathing OFF
=line-spacing= and INTO the capsule, so the divider stays an unbroken
glyph.*  Rationale: a glyph divider at =line-spacing 0= is *continuous,
portable (TTY + every GUI), and zero-cost*; svg-abutting bars and
=:stipple= backgrounds (the only ways to fill a line-spacing gap) are
fragile (hairline seams) and platform-limited (=:stipple= is X11-only).

*Contract:*
- Set =org-air-line-spacing= *default → 0* (restore tight S8 packing → the
  =│= divider touches row-to-row again).  The defcustom stays, so a user
  can re-introduce spacing knowing the divider trade-off.
- *Recover the capsule "breathing" without a buffer-level gap:* draw each
  pill capsule *slightly shorter than the line* — pill box height =
  =char-px-h − 2 × org-air-pill-vinset=, vertically centred (new defcustom
  =org-air-pill-vinset=, default *2* px).  Each capsule then carries its
  own top/bottom margin *inside its cell*, so a stacked column of capsules
  reads airy while the *cell grid (and the divider glyph) stays
  continuous*.  This reuses the pill box machinery; TTY is unaffected (no
  pills, no spacing — the glyph divider was always solid there).
- *Escape hatch (secondary, documented, NOT the default):* defcustom
  =org-air-divider-style= (='glyph default | 'svg).  ='svg draws each
  divider cell as an svg vertical bar sized to =char-h + line-spacing-px=
  so consecutive cells abut into a solid line *even with line-spacing > 0*
  — for users who re-enable spacing.  ='glyph + =line-spacing 0= is the
  shipped default.
- =[gui]= / display-only: =line-spacing= is a display var, =pill-vinset= is
  an svg attribute, the divider glyph =│= is *unchanged* → *fixtures HOLD*.

* D-P2 [MED] — clearer file glyph for the origin  [byte glyph + gui svg]
*Symptom:* =⌂= (house) before the filename reads as "home", not "file";
on item rows AND the inspector origin line.

*Contract:*
- *Glyph table* (=org-air-layout-glyphs=, key =origin=): retire the house.
  New tiers — PREFERRED =▤= (U+25A4 SQUARE WITH HORIZONTAL FILL — a lined
  "page", 1 col, text-presentation, widely covered), SAFE =▤=, ASCII =·=
  (a plain clear char for TTY).  *Avoid emoji* (📄/🗎 are width-2 / font-
  variable → would break the V6 1-col origin cell).
- *GUI svg (the real win):* defcustom =org-air-origin-icon-svg= (default
  =t=).  On a capable GUI, overlay the origin cell with a crisp drawn
  *document icon* — a rounded rectangle with a folded top-right corner —
  box-fit to the 1-col cell (=1 × char-px=, reusing the pill box-fit/soft-
  radius discipline), stroked in =org-air-face-group= (the origin face).
  New =org-air-view--svg-file-icon=.  Because it is locked to the single
  reserved column, *V6 pixel-lock holds*; turning it off shows =▤=.
- *Both surfaces:* =org-air-view--item-origin-raw= (item rows) and the
  inspector origin line already build =(org-air-view--glyph 'origin) " "
  …= — both pick up the new glyph; the svg overlay applies on the leading
  origin cell of each.
- =[byte]=: the origin glyph =⌂→▤= (and ASCII =·=) changes the origin
  column bytes on every item row + the inspector → regen + *BLESS*.  The
  document svg is a =[gui]= overlay over the =▤= cell (asserted text =▤=).
